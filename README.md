# 佳宝行测学习用

微信小程序的完整恢复工程，包含小程序前端、3 个云函数的业务源码与配套题库数据，以及本次恢复使用的自编工具。

## 工程结构

- miniprogram/：42 个页面、页面组件、业务脚本、样式、图片和本地数据。
- cloudfunctions/analysisNotes/、cloudfunctions/examBank/、cloudfunctions/studyNotes/：云函数源码、package.json 和配套数据。
- recovery/tools/：恢复期间使用的自编脚本；恢复后的日常开发不依赖这些脚本。
- docs/：恢复范围、已有验证结果和源文件校验清单。

## 在微信开发者工具中打开

1. 下载或克隆本仓库。
2. 在微信开发者工具的项目列表中点击“导入”，选择包含 project.config.json 的仓库根目录。
3. 工程已配置 AppID wx54427ecbe711c90c、小程序目录 miniprogram/、云函数目录 cloudfunctions/。
4. 云环境为 xingce-8877-d7gmih1gacff8de51，需要使用具有相应权限的微信开发者账号。

如需重新部署某个云函数，可在对应的云函数目录运行 npm install --omit=dev，再通过开发者工具部署；直接依赖为 wx-server-sdk@4.0.2。现有云函数仍可在原云环境中使用。
